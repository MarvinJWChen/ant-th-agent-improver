One container, four subsystems

A single Docker image on Render: a Node stage builds the React SPA, a Python stage serves it alongside the API. Everything the demo claims is computed inside that boundary. The Claude API is reached from exactly two places, and the validation labels are reachable from none.

Discovery: family-agnostic by construction

No evaluator anywhere in this pipeline mentions refunds, emails, or SLAs. The seeded failure families have to be recovered from behaviour alone — which is the only reason recovering them proves anything. Labels enter once, at the end, offline.

Replay: two clones, one frozen world

The safety argument rests on one mechanic. An arm never touches the recorded world — it gets a byte-for-byte copy, and every read and write lands on that copy. The baseline replays what production actually did; the candidate is re-executed, because a changed configuration may take a different path.

Provenance: what makes a capture evidence

Cached mode is the default so the demo runs with no API key. That is only defensible if a cached output can prove it came from a real run of the same program. Eleven fields are hashed at capture time and recomputed at load time.

What is real, what is recorded, what is synthetic

The distinction the demo lives or dies on. Everything that could be quietly faked is computed on the request that asks for it.

The guards that keep it honest

Five checks, each protecting one demonstrated claim. Three of them exist because they caught a real bug during the build.

  • Label leakage. No runtime module quotes the label table or names a seeded family. Build output is excluded, since it is generated rather than authored.
  • Capture-input determinism. Launches a second interpreter and compares hashes. Added after set-iteration order made pattern signatures vary between processes, silently invalidating every capture.
  • Capture freshness. Asserts every pattern still has a verified diagnosis. Added after widening a contract by one field changed the hashed inputs and dropped the whole app back to fixtures.
  • Replay safety. Distinct clone paths, identical start hashes, source world unchanged, external effects shadowed, unregistered tools blocked — plus an assertion that no network client exists anywhere in the replay package.
  • Gate behaviour. Proves the gate blocks on a control regression, on an unsafe effect, and on stale provenance — not just that it passes when everything is fine.
